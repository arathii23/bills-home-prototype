# Bills Home: clickable concept prototype

A clickable concept prototype for a product case study: turning a recharge into a household-bills routine ("Bills Home").

**Open it:** https://arathii23.github.io/bills-home-prototype/

- One file (`index.html`): no external requests, no cookies, nothing stored or sent.
- It opens with an optional step-by-step guide that can be closed at any step.
- It follows the look of public app screens but is **not an official Paytm product**. It uses no Paytm assets, and every name, amount and date is made up. Nothing is charged and no PIN is asked.
